# Implementation Plan: Vue.js Frontend Generator

**Branch**: `009-vue-frontend` | **Date**: 2026-04-11 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/009-vue-frontend/spec.md`

## Summary

Add Vue.js (Vue 3 + Vite + TypeScript + Tailwind v4 + Pinia) as a 3rd frontend option in ForgeKit CLI. The generator follows the React/Vite pattern: a standalone `VueGenerator` class in `src/generators/frontend/vue.ts`, 16 Handlebars templates in `src/templates/frontend/vue/`, and wiring into prompts, commands, CI, and Claude Code generators. Auth is optional; Pinia and Tailwind are always included.

## Key Decisions

1. **`buildPackageJson()` pattern** — plain JS object + `fs.outputJson()`, no Handlebars JSON template (avoids trailing-comma issue).
2. **Pinia always included** — no conditional; `stores/app.ts` always generated.
3. **`uiFramework = "tailwind"` silently set** when `frontend === "vue"` in `project.ts` (same as React).
4. **Vue Router v4** (not v5 — still in early release).
5. **Auth conditional in generator** (not templates) — Constitution rule 2.
6. **`vue-router` key for `add.ts`** — layer key is `"vue"` (not `"vue-vite"`), consistent with `"react"` mapping to `"react-vite"`.
