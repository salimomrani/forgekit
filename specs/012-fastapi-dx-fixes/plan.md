## Implementation Steps

### T001 — Templates: pytest.ini + pyrightconfig (backend)

Create:
- `src/templates/fastapi/pytest.ini.hbs` — static, no variables:
  ```ini
  [pytest]
  asyncio_mode = auto
  asyncio_default_fixture_loop_scope = function
  ```
- `src/templates/fastapi/pyrightconfig.json.hbs` — static:
  ```json
  {
    "pythonVersion": "3.12",
    "venvPath": ".",
    "venv": ".venv",
    "include": ["app", "tests"],
    "extraPaths": ["."]
  }
  ```

### T002 — Template: root pyrightconfig.json

Create `src/templates/root/pyrightconfig.json.hbs` — static (root generator passes `fastapi` flag; generation is conditional in TS, not in template):
```json
{
  "pythonVersion": "3.12",
  "venvPath": "backend",
  "venv": ".venv",
  "include": ["backend/app", "backend/tests"],
  "extraPaths": ["backend"]
}
```

### T003 — Update requirements.txt.hbs

Add `pytest-asyncio==0.24.0` to `src/templates/fastapi/requirements.txt.hbs`.

### T004 — Update FastAPIGenerator

In `src/generators/fastapi/index.ts`, add to the `Promise.all([...])`:
```ts
renderAndWrite("fastapi/pytest.ini.hbs", path.join(backendDir, "pytest.ini"), data),
renderAndWrite("fastapi/pyrightconfig.json.hbs", path.join(backendDir, "pyrightconfig.json"), data),
```

### T005 — Update RootGenerator

In `src/generators/root/index.ts`, add to `Promise.all([...])`:
```ts
...(this.config.backendType === "fastapi"
  ? [renderAndWrite("root/pyrightconfig.json.hbs", path.join(this.projectDir, "pyrightconfig.json"), data)]
  : []),
```

### T006 — Update README.md.hbs (venv step)

In `src/templates/root/README.md.hbs`, for the FastAPI quickstart block, replace:
```
cd backend && pip install -r requirements.txt
```
with:
```
cd backend && python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
```

### T007 — Update backend.md.hbs (HTTP codes + venv note)

In `src/templates/claude-code/rules/backend.md.hbs`, FastAPI section, add:
```
- **HTTP status codes:** POST (create) → `201`, GET → `200`, PUT/PATCH → `200`, DELETE → `204`
- **Tests:** run via `.venv/bin/pytest` (not bare `pytest` — not in PATH until venv is activated)
```

### T008 — New unit test: FastAPIGenerator

Create `src/generators/fastapi/__tests__/fastapi.test.ts` following the pattern of `src/generators/claude-code/__tests__/claude-code.test.ts`:
- `beforeEach`: `fs.mkdtemp(...)` → `tmpDir`
- `afterEach`: `fs.remove(tmpDir)`
- Assertions: `backend/pytest.ini` exists + contains `asyncio_mode`, `backend/pyrightconfig.json` exists + contains `pythonVersion`, `backend/requirements.txt` contains `pytest-asyncio`

### T009 — Extend e2e S2 test

In `src/__tests__/e2e.test.ts`, S2 test, add:
```ts
expect(await fs.pathExists(path.join(projectDir, "backend/pytest.ini"))).toBe(true);
expect(await fs.pathExists(path.join(projectDir, "backend/pyrightconfig.json"))).toBe(true);
expect(await fs.pathExists(path.join(projectDir, "pyrightconfig.json"))).toBe(true);
```
